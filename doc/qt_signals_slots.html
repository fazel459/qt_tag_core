⚡ مستند Signals & Slots کلاس‌های qt_tag_core

مرجع کامل کلاس‌های Qt، سیگنال‌ها، اسلات‌ها و متدهای عمومی بر اساس سورس‌کد واقعی

⚡ C++17 / Qt 📡 ۱۷ کلاس 🔔 Signals/Slots 🏭 از سورس واقعی

🗺 ۱. نقشه ارتباطات (Signal → Slot)

ITagDriver (Modbus/OPC UA/MQTT) ↓ publish(topic, TagValue) TagBus (pub/sub) ↓ subscribe("tags/#") RealtimeCache • RuleEngine • CurrentStateWriter • BatchHistorianWriter ↓ WebSocketHandler.publishTagUpdate() ↓ broadcast کلاینت‌های WebSocket
QTcpServer::newConnection → HttpServer::onNewConnection (private slot)
QWebSocketServer::newConnection → WebSocketServer::onNewConnection (private slot)
QTimer::timeout → WebSocketHandler::heartbeat / flushPendingTagUpdates

🎨 ۲. راهنمای نشانه‌ها

signal سیگنال خروجی کلاس — slot اسلات (عمومی/خصوصی) — method متد عمومی — static متد استاتیک

QObject کلاس دارای Q_OBJECT (قابلیت signals/slots) — plain C++ کلاس ساده بدون متا-آبجکت

💡 نکته معماری
هسته پایپ‌لاین (TagBus، فیلترها، RuleEngine) عمداً plain C++ و بدون signal است تا overhead متا-آبجکت حذف شود؛ ارتباط از طریق callback (std::function) انجام می‌شود. لایه API و ذخیره‌سازی QObject هستند.

🚌 TagBus

TagBusplain C++tagbus

پیام‌رسان pub/sub سبک با پشتیبانی wildcard (# و prefix/#). جایگزین signal برای مسیر داده پربسامد.

public methods

void subscribe(const QString& filter, Handler handler); // Handler = fn(const BusMessage&)
void publish(const QString& topic, const TagValue& value);

مثال اتصال

bus.subscribe("tags/#", []( const BusMessage& m ){
    if (m.topic.endsWith("/update")) { /* پردازش */ }
});
