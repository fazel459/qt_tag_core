📋 نمای کلی پروژه

Tag Core چیست؟

Tag Core یک موتور SCADA/Historian صنعتی است که برای جمع‌آوری، پردازش، ذخیره‌سازی و مدیریت داده‌های سنسورها طراحی شده است. این سیستم از پروتکل‌های صنعتی Modbus TCP/RTU، MQTT و OPC UA پشتیبانی می‌کند.

ویژگی‌های اصلی

✅ پیاده‌سازی شده

  • TagBus (Pub/Sub Engine)
  • Driver Framework (Modbus TCP/RTU, MQTT, Simulator)
  • Software Filter Chain (7 نوع فیلتر)
  • Rule Engine (9 نوع آلارم)
  • Notification / Webhook
  • Computed Tags
  • Historian با Downsampling
  • Archive Manager
  • Batch Read (کارت‌های 16 سنسوره)

⏳ در دست توسعه

  • OPC UA Driver (نیاز به build کتابخانه)
  • API Layer (REST + WebSocket)
  • UI / Tag Management
  • Alarm Shelving / Suppression
  • DNP3 Driver
  • Report Generation
  • Web Dashboard

مرحله 1: نصب PostgreSQL

# دانلود و نصب PostgreSQL از:
https://www.postgresql.org/download/windows/

# در حین نصب:
- Port: 5432
- Superuser: postgres
- Password: (یک رمز عبور قوی انتخاب کنید)

مرحله 2: نصب TimescaleDB

# دانلود TimescaleDB از:
https://docs.timescale.com/self-hosted/latest/install/installation-windows/

# پس از نصب، در psql:
# اضافه کردن به postgresql.conf:
shared_preload_libraries = 'timescaledb'

# ری‌استارت PostgreSQL

مرحله 3: ایجاد دیتابیس

-- اتصال به psql
psql -U postgres

-- ایجاد دیتابیس
CREATE DATABASE tagsdb;

-- اتصال به دیتابیس
\c tagsdb

-- فعال‌سازی TimescaleDB
CREATE EXTENSION IF NOT EXISTS timescaledb;

مرحله 4: تنظیمات bootstrap.json

{
    "database": {
        "host": "localhost",

        "database_name": "tagsdb",

مرحله 7: ایجاد کاربر (اختیاری)

-- اعطای دسترسی‌ها

GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO tagcore;
GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO tagcore;

🔍 عیب‌یابی

مشکلات رایج

مشکلعلتراه‌حل
خطای offset در PostgreSQL offset کلمه کلیدی است استفاده از scaling_offset
QVariant::toDouble(default) خطا می‌دهد Qt 5.14 این متد را ندارد استفاده از helper functions
Qt::SkipEmptyParts موجود نیست Qt 5.14 از QString::SkipEmptyParts استفاده می‌کند تغییر به QString::SkipEmptyParts
QNetworkRequest خطا می‌دهد Most Vexing Parse استفاده از QUrl requestUrl(url)
MQTT متصل نمی‌شود QHostAddress("localhost") resolve نمی‌شود استفاده از QHostAddress::LocalHost
MQTT پیام دریافت نمی‌کند Multiple inheritance problem استفاده از lambda برای سیگنال‌ها
QVector::dequeue خطا می‌دهد QVector متد dequeue ندارد استفاده از QQueue
QSqlError incomplete type include موجود نیست اضافه کردن #include <QSqlError>
