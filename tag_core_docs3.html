۱. نمای کلی پروژه

۴. قابلیت‌های Core

Modbus Polling (معماری کارت‌ها)

هر کارت = ۱۶ اسلات ثابت، هر سنسور = ۱ رجیستر (۲ بایت). کل کارت همیشه ۱۶ رجیستر می‌فرستد.

آدرس‌دهی (Slot-based)

cardIndex  = address / 16
sensorIndex = address % 16
card.startAddress  = cardIndex * 16
card.totalRegisters = 16            # همیشه کل کارت
sensor.registerOffset = sensorIndex # اسلات ثابت
decode: byteOffset = registerOffset * 2

User Management

جدول users

CREATE TABLE users (
    user_id BIGSERIAL PRIMARY KEY,
    username TEXT NOT NULL UNIQUE,
    password_hash TEXT NOT NULL,
    salt TEXT NOT NULL,
    display_name TEXT DEFAULT '',
    role TEXT DEFAULT 'operator',
    is_active BOOLEAN DEFAULT true,
    last_login_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ DEFAULT now()
);
کاربر پیش‌فرض: admin / admin123 (خودکار ساخته می‌شود). رمز با salt + SHA-256 hash می‌شود.

Authentication

پیش‌فرض غیرفعال (حالت development). فعال‌سازی:
UPDATE system_settings SET value_text='true' WHERE key='api.auth.enabled';

۶. راهنمای تست

👤 تست User Management (PowerShell)
$login = Invoke-RestMethod -Uri "http://127.0.0.1:8082/api/v1/auth/login" -Method Post `
  -Body (@{username="admin"; password="admin123"} | ConvertTo-Json) -ContentType "application/json"
$token = $login.token

# اطلاعات من
Invoke-RestMethod -Uri "http://127.0.0.1:8082/api/v1/auth/me" -Headers @{Authorization="Bearer $token"}

# لیست کاربران
Invoke-RestMethod -Uri "http://127.0.0.1:8082/api/v1/users" -Headers @{Authorization="Bearer $token"}

# ساخت کاربر viewer
Invoke-RestMethod -Uri "http://127.0.0.1:8082/api/v1/users" -Method Post -Headers @{Authorization="Bearer $token"} `
  -Body (@{username="guest"; password="1234"; role="viewer"} | ConvertTo-Json) -ContentType "application/json"
